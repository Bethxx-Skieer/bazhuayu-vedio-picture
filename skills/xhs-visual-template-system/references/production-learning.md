# Production learning

## Divide work by production method

- Use official assets for logo and recognizable IP.
- Use real screenshots for product proof.
- Use AI image generation only for atmosphere or a coherent illustration.
- Use HTML/CSS/SVG for Chinese copy, capsules, rules, borders, callouts, speech bubbles, and exact geometry.
- Never ask image generation to solve Chinese typography and precise layout simultaneously.

## Lock structure before styling

Confirm the title zone, logo slot, screenshot or IP zone, one focal point, and final crop before changing gradients, shadows, or decorations. Do not make variants until one base composition is accepted.

## Keep one visual language

Do not mix glossy 3D, flat vector, crayon hand drawing, photography, and glass UI on one page. Match contour, material, lighting, saturation, shadow softness, perspective, and edge sharpness.

Prefer the original official IP when identity consistency matters. Reject regenerated IP with unstable eyes, limbs, silhouette, or emotional tone.

For reusable work-scene templates, use the neutral transparent IP without hats, confetti, streamers, or party props. Celebration styling is scenario-specific and must not be the template default.

For a glass/IP speech cover, keep the bubble body almost pure white, use a pale-blue outer edge and broad low-opacity blue shadow, and use pale ice-blue capability tags. A gray interior makes the title zone look dull; strengthen the boundary instead of darkening the surface.

## Rebuild instead of patching

Build joined shapes such as speech bubbles as one path. Rebuild a component when it needs repeated corrective offsets, multiple cover-up pseudo-elements, or works alone but fails in the assembled page.

Use one bounding box and one coordinate system per composite component.

## Audit the complete page

Check canvas edge to logo, logo to title, headline line spacing, headline to subtitle, context label to screenshot, component-to-component gaps, card top padding, and last line to card bottom.

Render at `1080×1440`; inspect full size and phone-thumbnail size. Preserve accepted background, brand color, IP, and layout decisions while fixing an unrelated issue.

## Full-background scenario covers

- Generate the atmosphere image directly at `1080×1440` or 3:4; reserve the upper 38–42% as a low-contrast title zone.
- Treat the composition as three modules only: large headline, one support line, and one visual scene.
- Keep logos, precise Chinese copy, numbers, and callouts in HTML.
- When the scene contains several similar panels, attach labels to the exact panel or row they explain. A detached label row fails because it names concepts without decoding the visual.
- Use object/action pairs such as `结算数据 / 获取结算账单`; use green only for successful completion and orange only for exceptions.
- Keep tool or Agent icons small and subordinate. Prefer web tables, status rows, and digital matching cues over physical paper or ledger metaphors for online reconciliation.

## Current strategy

The current template set is sufficient for short-term production. Prefer adapting an existing template. Add a new component or template only after a real content task exposes a stable missing page job.
