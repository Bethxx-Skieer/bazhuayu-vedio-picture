# 八爪鱼冰蓝模板索引

生产目录：`assets/templates/octopus-blue/`。

索引用于选择模板，不是逐个模板的操作手册。所有模板共用主题、组件、文案和设计规则；只有真正需要动态生图的模板才读取额外生图规则。

## 封面

| 模板 | 主要用途 | 必要素材 | 附加规则 |
|---|---|---|---|
| `封面-截图.html` | 用一张真实产品截图支撑核心价值 | 能证明主张的产品截图 | 截图证据规则 |
| `封面-氛围.html` | 没有截图时表达一个简洁判断或主题 | 已批准的固定氛围背景 | 无 |
| `封面-IP-手绘.html` | 用亲和、轻松的小八口吻表达价值 | 固定手绘小八素材 | 无，不重新生成 IP |
| `封面-IP-3D玻璃.html` | 用更科技化的3D小八表达工作场景 | 固定中性3D小八素材 | 无，不重新生成 IP |
| `封面-IP-合作.html` | 表达两个品牌IP围绕真实任务界面的协作；当前版本为WorkBuddy与小八 | 独立电脑透明素材、真实任务截图、固定小八、固定WorkBuddy、联合标识 | 无，不重新生成双IP；按“背景→电脑→截图→两个IP”叠加 |
| `封面-联合品牌-截图.html` | 表达八爪鱼RPA与客户或伙伴围绕真实任务结果的联合方案，不依赖IP角色 | 双方Logo与名称、独立电脑透明素材、真实任务截图 | 无，不放IP；按“背景→电脑→截图→联合品牌”分层，替换伙伴Logo时保留完整标识 |
| `封面-IP-业务场景.html` | 用完整业务场景解释2–4个对象、动作或状态 | 动态生成的3:4无文字场景图 | [场景封面生图规则](image-generation-scenario-cover.md) |
| `封面-视频演示.html` | 用真实产品证明画面制作3:4视频封面 | 真实截图或录屏帧 | 独立封面，不再派生视频内页 |

## 内页

| 模板 | 主要用途 | 必要素材 | 附加规则 |
|---|---|---|---|
| `内页-正文说明.html` | 解释一个步骤、机制或观点 | 结构化正文 | 无 |

## 选择顺序

1. 先判断页面是封面还是内页。
2. 封面优先根据证据类型选择：真实截图、固定氛围、固定 IP、动态场景或视频证明。
3. 有真实产品截图时优先用 `封面-截图.html`；不要用氛围图冒充产品证据。
4. 有IP互动诉求时使用 `封面-IP-合作.html`；只有联合品牌和真实成果时使用 `封面-联合品牌-截图.html`，不要为了填空强行加入IP。
5. 手绘、3D玻璃和IP合作模板使用已批准的固定IP素材；合作模板将电脑、真实截图和两个IP作为独立层，不临时重画角色或伪造界面。
6. 只有 `封面-IP-业务场景.html`需要读取独立生图规则。
7. `封面-视频演示.html`是独立封面模板，不创建或维护配套视频内页。
8. 所有路径保持相对；复制模板时同时复制它依赖的 CSS 和 `assets/`。

PNG预览位于 `examples/octopus-blue-gallery/`，文件名与HTML模板一致；`模板总览.png`仅用于浏览，不是模板源文件。
