# 封面-IP-业务场景｜生图规则

这份规则只用于 `assets/templates/octopus-blue/封面-IP-业务场景.html`。其他八爪鱼冰蓝模板使用固定背景、固定 IP 或真实截图，不读取本文件。

## 生成目标

生成一张完整、连贯的3:4企业自动化场景背景。图片负责氛围、对象和动作关系；标题、Logo、数字、中文标签和场景标注全部由HTML完成。

## 生成前输入

- 一个明确业务场景，例如跨境对账、财务核对、舆情监测或数据同步；
- 2–4个必须出现的业务对象或状态；
- 每个对象对应的动作或结果；
- 已批准的小八参考素材；默认使用 `assets/octopus-3d-work-neutral.png`；
- 最终标题、支持线和需要标注的对象清单。

缺少真实产品截图时，不得在生成图中伪造可被误认为真实产品界面的细节。

## 画面约束

1. 直接生成 `1080×1440` 或严格3:4比例。
2. 上方38%–42%保留低对比、低细节标题安全区。
3. 小八和核心业务对象集中在下方58%–62%，形成一个清晰视觉中心。
4. 场景必须能够找到2–4个明确标注目标；相似面板要有可辨识的位置或状态差异。
5. 保持八爪鱼冰蓝主题：冰蓝白背景、品牌蓝结构、绿色仅表示完成、橙色仅表示异常或人工动作。
6. 不在生成图中加入Logo、标题、数字、中文标签、对话气泡或场景标注。
7. 不生成庆典帽、彩带、礼花等活动元素，除非内容明确是节日或庆典。
8. 不混合手绘、照片、亮面3D、玻璃UI等多种视觉语言。

## IP一致性

- 使用运行环境可用的位图生图工具，并把已批准的小八素材作为直接参考图。
- 优先保持眼睛、触手数量、轮廓、材质、主蓝色和情绪的一致性。
- 如果小八出现畸形、额外肢体、轮廓漂移或情绪不符，必须重新生成，不能用HTML遮盖修复。

## 输出与装配

1. 将最终背景保存到模板的 `assets/`，使用 `scenario-<topic>-bg.png` 命名。
2. 替换 `封面-IP-业务场景.html` 中的背景图片和替代文本。
3. 根据新场景重新定位全部 `scene-callout`；不得沿用示例坐标。
4. 标注使用“对象或状态／动作”结构，例如“结算数据／获取结算账单”。
5. 导出后同时检查1080×1440原图和手机缩略图。

## 拒绝条件

- 标题安全区过于繁忙；
- 小八身份不稳定；
- 对象关系无法读懂；
- 场景像产品截图但并非真实界面；
- 标注找不到明确目标；
- 生成图包含错误中文、伪Logo或无依据数字。
